INTRO VIDEO DIRECTORY
====================

Place your website intro video into this folder: `public/video/`

File naming guidelines for your intro video:
- File path: `public/video/intro.mp4` (or `intro.webm` / `intro.mov`)

HOW IT WORKS:
-------------
1. Save your video file as `intro.mp4` inside `public/video/`.
2. When you run `npm run dev` or deploy the site, the full page intro video on the website will automatically play your new video file!
3. Supported formats: .mp4, .webm, .mov
