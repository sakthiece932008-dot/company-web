WHY THIS WORKS ON OTHER COMPUTERS:
----------------------------------
Because these images are placed inside the `public/team/` directory of the project,
they become part of the static website assets. When you run `npm run dev` or `npm run build`
and open the website from another computer (or deploy it to Vercel/Netlify/GitHub Pages/Server),
all the images will load seamlessly across any device or computer!
